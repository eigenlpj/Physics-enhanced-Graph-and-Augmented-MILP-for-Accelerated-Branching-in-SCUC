# Physics-enhanced Graph and Augmented MILP for Accelerated Branching in Security-Constrained Unit Commitment
(Security-Constrained Unit Commitment) SCUC  is essential for day-ahead market clearing and is typically formulated as a MILP problem, solved by  B&amp;C-based solvers.We proposes a physics-informed  GNN branching framework incorporating two novel modules:(i) Pgraph  and (ii) an AMILP method.

Peijie Li, Jiaming Li, Xiaoqing Bai
