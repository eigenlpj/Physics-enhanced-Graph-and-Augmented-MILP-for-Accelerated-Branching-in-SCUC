# Physics-enhanced-Graph-and-Augmented-MILP-for-Accelerated-Branching-in-SCUC
SCUC  is essential for day-ahead market clearing and is typically formulated as a MILP problem, solved by  B&amp;C-based solvers.We proposes a physics-informed graph GNN branching framework incorporating two novel modules:(i) Pgraph  and (ii) an AMILP method.
